# Lab System

A modern laboratory management system built using ASP.NET Core MVC for managing chemicals, experiments, reactions, equipment, and researcher workflows.


## Features

### Authentication & Authorization
- ASP.NET Core Identity
- Role-based access control
- Admin, Supervisor, Researcher, LabManager roles

### Dashboard
- Real-time statistics
- Inventory alerts
- Experiment approval statistics
- Recent activity tracking

### Chemicals Management
- Add/Edit/Delete chemicals
- Hazard classifications
- Expiry monitoring
- Stock tracking
- Purity and storage management

### Equipment Management
- Equipment inventory
- Status tracking
- Maintenance monitoring

### Experiment Workflow
- Structured experiment reports
- Theory, procedure, calculations, final results
- Experiment approval system
- Chemical usage tracking

### Reactions
- Reaction step management
- Chemical equations
- Recursive reaction steps

### Researcher Profiles
- Research groups
- Qualifications
- Department information
- Research areas

### File Management
- Upload PDFs and experiment images
- Export experiment reports to PDF
